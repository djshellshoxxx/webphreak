About this format

Analog caller ID rides on Bell 202 audio-frequency FSK (1200 Hz = mark/1, 2200 Hz = space/0) sent in the silent interval between the first and second ring, at 1200 baud, 8-N-1 framing. A message opens with a channel-seizure pattern and a mark-signal burst, then the data bytes.

SDMF (message type 0x04): 8 ASCII digits of date/time (MMDDHHmm) followed by the calling number, or the letter O (out of area) / P (private).
MDMF (message type 0x80): a sequence of parameter records. This decoder reads the common ones — 0x01 date/time, 0x02 calling number, 0x07 calling name, 0x04/0x08 reason-for-absence codes — and shows any other parameter type as raw hex.

This is a software FSK demodulator reading whatever audio you give it. It has not been validated against a hardware caller-ID receiver or a large corpus of real-world captures, and noisy or low-quality recordings will decode poorly or not at all. It only reads audio you provide; it has no line, modem, or telecom network access and cannot produce or inject a caller ID signal.
