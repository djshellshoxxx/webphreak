History & Sources

How the tone values were researched, what each status label means, the complete catalog generated from the same data the players use, and every cited source.

Research methodology

Values came from earlier versions of this site and from user-supplied descriptions, which were treated as research leads rather than authority. Each value was checked against standards, manufacturer or regulator documents, patents, encyclopedias and historical hobbyist texts. Conflicts are kept visible rather than averaged away. Corrections and open items are listed in the research notes.

Limits of this pass. The build environment could not fetch web pages, so sources were consulted through search-engine summaries only, and no primary standard (ITU-T, Telcordia, BSTJ, ETSI, ARINC) was opened. For that reason no entry is marked “Verified”. The requested source spreadsheet could not be read either (its host was blocked), so its rows are not reconciled here.

  • ◐ Secondary sources values agree across secondary sources.
  • ⇄ Disputed sources conflict; the implemented variant and the alternative are listed.
  • ≈ Approximate simplified rendering of a real signal.
  • ? Unverified no supporting source found; kept as a research item.
  • ◇ Illustrative demonstration sound only; not a valid protocol frame, code or message.
